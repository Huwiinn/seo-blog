UI 모션 용어를 알면 AI 코딩 도구에 보내는 요청이 한 줄로 줄어듭니다. 모호한 형용사를 늘어놓는 대신 인터랙션의 이름을 쓰고, 이름으로 부족할 때만 동작 설명을 덧붙이면 됩니다. 이 글은 그 이름 54종을 여섯 분류의 표로 정리한 사전입니다.

바이브코딩(Vibe Coding)으로 화면을 만들 때 표에서 이름을 찾아 쓰면 됩니다. 모션 용어 글의 전체 구성은 [UI 모션 가이드](/posts/ui-motion-guide-index)에서 볼 수 있습니다.

## 메뉴 모션 9종

메뉴와 내비게이션이 열리고 선택이 옮겨 가는 방식에 붙은 이름입니다. 용어별 설명은 [메뉴 모션 9개 해설](/posts/menu-motion-names)에 있습니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 플로팅 바텀 내비 | Floating Bottom Nav | 하단에 떠 있는 메뉴바의 버튼을 누르면 바 위로 패널이 펼쳐짐 |
| 슬라이드 탭 | Slide Tabs | 선택 표시가 탭 사이를 미끄러지듯 옮겨 감 |
| 칩 탭 | Chip Tabs | 색 칩이 누른 탭 쪽으로 탄성 있게 튀어 옮겨 감 |
| 스태거드 드롭다운 | Staggered Dropdown | 버튼을 누르면 메뉴 항목이 하나씩 차례로 내려옴 |
| 플라이아웃 링크 | Flyout Link | 링크에 마우스를 올리면 바로 아래에 안내 패널이 부드럽게 뜸 |
| 시프팅 드롭다운 | Shifting Dropdown | 다른 메뉴로 옮겨도 상자가 닫히지 않고 모양만 바꿔 따라옴 |
| 리트랙팅 사이드바 | Retracting Sidebar | 버튼을 누르면 옆 메뉴가 좁아져 아이콘만 남음 |
| 코너 내비 | Corner Nav | 모서리 버튼을 누르면 그 모서리에서 메뉴 화면이 펼쳐짐 |
| 호버 플립 내비 | Hover Flip Nav | 메뉴 글자가 위로 밀려 올라가고 다른 색 글자로 바뀜 |

## 버튼 모션 9종

버튼의 생김새와 반응 방식에 붙은 이름입니다. 용어별 설명은 [버튼 모션 9개 해설](/posts/button-motion-terms)에 있습니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 웻 페인트 | Wet Paint Button | 버튼 아래로 물감이 계속 흘러내리고, 마우스를 올리면 색이 진해짐 |
| 인크립트 | Encrypt Button | 글자가 기호로 뒤섞였다가 왼쪽부터 한 글자씩 되돌아옴 |
| 닷 익스팬드 | Dot Expand Button | 왼쪽의 작은 점이 화살표 동그라미로 커지고 버튼이 검정으로 반전됨 |
| 마그넷 | Magnet Button | 동그란 버튼이 커서 쪽으로 끌려오고 둘레의 글자 고리가 회전함 |
| 햄버거 | Hamburger Button | 세 줄 메뉴 아이콘을 누르면 회전하며 닫기(X) 모양으로 바뀜 |
| 스플래시 | Splash Button | 마우스를 올리면 살짝 커지며 바깥 링이 사라지고, 누르면 꾹 눌림 |
| 샤이니 | Shiny Button | 커서를 따라다니는 은은한 흰 빛이 버튼 위에 생김 |
| 드로우 아웃라인 | Draw Outline Button | 테두리 선이 위, 오른쪽, 아래, 왼쪽 순서로 그려짐 |
| 스포트라이트 | Spotlight Button | 밝은 원이 커서를 따라 움직이고 원과 겹친 글자는 색이 뒤집힘 |

## 마이크로 인터랙션 9종

누르기, 당기기, 밀기 같은 작은 조작에 화면이 반응하는 방식입니다. 버튼 모프, 체크 드로우, 모달 스케일인은 동작을 풀어 쓴 서술형 이름입니다. 이 셋은 원하는 상태 변화를 뒤에 함께 적어야 정확합니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 리플 | Ripple | 누른 자리에서 물결이 바깥으로 퍼짐 |
| 버튼 모프 | Button morph | 버튼 모양이 로딩 원 같은 다른 상태로 바뀜 |
| 토글 | Toggle | 스위치 모양으로 켜짐과 꺼짐을 전환함 |
| 체크 드로우 | Checkbox draw | 체크 표시가 선을 따라 차례로 그려짐 |
| 풀 투 리프레시 | Pull-to-refresh | 목록을 아래로 당기면 내용을 새로 고침 |
| 스와이프 투 딜리트 | Swipe to delete | 항목을 옆으로 밀어 목록에서 삭제함 |
| 드래그 앤 드롭 | Drag & drop | 항목을 잡아 끌어 다른 자리에 놓음 |
| 모달 스케일인 | Modal scale-in | 확인창이 작은 크기에서 점점 커지며 나타남 |
| 인피니트 스크롤 | Infinite scroll | 목록 끝에 가까워지면 다음 항목을 더 불러옴 |

## 텍스트 모션 9종

제목과 문구가 나타나고 바뀌는 방식에 붙은 이름입니다. 용어별 설명은 [텍스트 모션 9개 해설](/posts/text-motion-terms)에 있습니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 드로우 서클 | Draw Circle Text | 강조할 단어 둘레에 손으로 그린 듯한 동그라미가 그려짐 |
| 배니시 | Vanish Text | 단어가 작아지며 사라지고 다음 단어가 통 튀며 나타남 |
| 버블 텍스트 | Bubble Text | 마우스를 올린 글자가 굵어지고 옆 글자도 조금씩 굵어짐 |
| 스플릿 플랩 | Split Flap Display | 공항 안내판처럼 글자판이 넘어가며 글자가 맞춰짐 |
| 리빌 링크 | Reveal Links | 큰 글자가 한 글자씩 위로 굴러 올라가고 같은 글자가 아래에서 다시 나타남 |
| 컷아웃 로더 | Cutout Text Loader | 글자 모양 구멍으로 뒤 사진이 비치며 밝아졌다 어두워짐 |
| 스피닝 박스 | Spinning Box Text | 단어가 상자의 면처럼 굴러 다음 단어로 바뀜 |
| 벨로시티 | Velocity Text | 빨리 스크롤할수록 글자 띠가 빠르게 흐르고 더 기울어짐 |
| 핏 텍스트 | Fit Text To Container | 글자 크기가 상자 너비에 꽉 차도록 자동으로 맞춰짐 |

## 컴포넌트 모션 9종

카드, 헤더, 알림처럼 웹 화면을 이루는 부품의 움직임입니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 호버 리프트 | Hover lift | 마우스를 올리면 카드가 살짝 떠오름 |
| 스티키 헤더 | Sticky header | 스크롤해도 메뉴가 화면 맨 위에 붙어 있음 |
| 아코디언 | Accordion | 제목을 누르면 세부 내용이 아래로 펼쳐지고 다시 접힘 |
| 토스트 | Toast (Snackbar) | 화면 한쪽에 작은 알림이 잠깐 떴다가 저절로 사라짐 |
| 바텀 시트 | Bottom sheet | 메뉴·옵션 창이 화면 아래에서 위로 올라옴 |
| 캐러셀 | Carousel | 슬라이드를 옆으로 한 장씩 넘김 |
| 플립 카드 | Flip card | 카드가 입체적으로 뒤집히며 뒷면 정보가 보임 |
| 진행 바 | Scroll progress | 글을 읽은 만큼 상단 바가 차오름 |
| 셰이크 | Shake | 잘못 입력하면 입력 칸이 좌우로 흔들려 오류를 알림 |

## 차트 모션 9종

막대, 선, 도넛 같은 그래프가 나타나고 바뀌는 방식에 붙은 이름입니다. 용어별 설명은 [차트 모션 9개 해설](/posts/chart-motion-terms)에 있습니다.

| 용어 | 영문 이름 | 동작 |
| --- | --- | --- |
| 바 그로우 | Bar grow | 막대가 바닥에서 위로 자라남 |
| 라인 드로우 | Line draw | 그래프 선이 왼쪽부터 차례로 그려짐 |
| 도넛 필 | Donut fill | 도넛 차트가 한 바퀴 돌며 비율만큼 채워짐 |
| 스택 바 | Stacked bar | 한 막대 안에 하위 항목이 차례로 쌓여 올라감 |
| 진행 링 | Progress ring | 동그란 링이 달성률이나 진행률만큼 차오름 |
| 스파크라인 | Sparkline | 표 칸 안에 아주 작은 추이 그래프를 넣음 |
| 툴팁 | Tooltip | 마우스를 올리면 그 지점의 상세 값이 말풍선으로 뜸 |
| 강조 펄스 | Highlight pulse | 바뀐 숫자 칸이 깜빡이는 파동으로 눈에 띔 |
| 정렬 모션 | Sort animation | 순위가 바뀌면 막대가 미끄러지듯 새 자리로 이동함 |

바 그로우, 라인 드로우, 도넛 필, 강조 펄스, 정렬 모션은 하나로 정해진 공식 이름이 아니라 동작을 설명하는 서술형 이름입니다. 이 다섯 개는 원하는 움직임을 뒤에 구체적으로 적습니다.

## UI 모션 용어는 요청문에 어떻게 넣나요?

적용할 대상과 모션 이름을 한 문장에 넣으면 됩니다. 이름만으로 다른 모양이 나오면 동작 설명 한 줄을 덧붙입니다.

1. 만들 화면에 맞는 분류의 표에서 이름을 고릅니다.
2. 대상과 영문 이름을 한 문장에 넣어 요청합니다.
3. 결과가 다르면 표의 동작 설명을 한 줄로 덧붙입니다.
4. 서술형 이름은 처음부터 동작을 함께 적습니다.

아래는 이 순서대로 쓴 요청문 두 줄입니다. 첫 줄에는 이름만 넣었고, 둘째 줄에는 동작 설명까지 붙였습니다.

```text
요금제 탭은 slide tabs로 만들어 줘.
정렬 메뉴는 staggered dropdown으로, 버튼을 누르면 항목이 하나씩 차례로 내려오게 해 줘.
```

결제 화면에 쓰는 모션 이름은 이 사전의 여섯 분류에 없어서 [결제 화면 모션 9개 해설](/posts/checkout-motion-names)에 따로 정리했습니다. 카메라 무빙 용어는 [카메라 무빙 가이드](/posts/ai-video-camera-motion-guide)에 있습니다. 화면 전체의 분위기를 이름으로 지정하는 방법은 [UI 스타일 10가지](/posts/ui-style-prompts)에서 다룹니다.

## 자주 묻는 질문

### 토스트와 스낵바는 다른 것인가요?

이 사전에서는 같은 알림을 가리킵니다. 머티리얼 디자인 계열에서는 토스트를 스낵바라고도 부릅니다.

### 캐러셀을 자동으로 넘길 때 함께 요청할 것이 있나요?

멈춤 버튼을 함께 요청합니다. 자동으로 넘어가는 캐러셀은 사용자가 멈출 수 있어야 접근성을 확보할 수 있습니다.

### 발표 자료(PPT)에도 이 이름을 쓸 수 있나요?

쓸 수 있습니다. 발표 자료에 넣을 때는 그 동작을 보여 주는 시연 애니메이션으로 만들어 달라고 덧붙입니다. 차트라면 움직임을 애니메이션으로 넣어 달라고 요청합니다.
