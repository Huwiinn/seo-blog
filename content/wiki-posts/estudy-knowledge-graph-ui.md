estudy의 지식 그래프 UI는 Canvas 2D 영역과 사이드바 하나로 932개 노드를 보여 줍니다. 읽기 페이지는 JavaScript 번들 없는 정적 HTML로 두고, 그래프 페이지 한 곳에만 Rust WebAssembly를 씁니다. 좌표와 엣지는 빌드 때 미리 계산해 파일로 만들어 둡니다.

estudy는 개발자 rlaope가 공개한 학습 사이트입니다. 이 글은 [지식 그래프 페이지](https://rlaope.github.io/graph.html)의 화면 구성, 데이터 준비 방식, 디자인 토큰(design token)을 차례로 다룹니다. 수치는 2026년 11월 기준입니다. 사이트 전체 소개는 [estudy 지식 베이스 소개 글](/posts/estudy-knowledge-base-overview)에 있습니다.

노드 932개에는 노트 외에 색인 페이지와 허브 노드도 들어 있어 노트 913개보다 많습니다.

## 지식 그래프 UI는 어떤 화면으로 구성되나요?

왼쪽의 Canvas 2D 영역과 오른쪽의 고정 폭 320px 사이드바로 나뉜 2분할 화면입니다. 화면 폭이 820px 이하이면 사이드바가 아래로 내려갑니다.

화면에는 한글 초성 검색을 지원하는 검색창과 섹션 필터가 있습니다. 노드를 선택하면 사이드바에 그 노트의 본문 발췌가 나타납니다. 선택한 노드의 1-hop 또는 2-hop 이웃만 남긴 에고 네트워크(ego network)도 볼 수 있습니다.

키보드 단축키는 다섯 가지입니다.

| 키 | 동작 |
| --- | --- |
| `/` | 검색창으로 포커스 이동 |
| `Esc` | 선택과 필터 초기화 |
| `0` | 전체 그래프를 화면에 맞춤 |
| `e` | 에고 네트워크 전환 |
| `Tab` | 포커스 링으로 노트 사이 이동 |

## 932개 노드를 그리는 데이터는 어떻게 준비하나요?

좌표와 엣지를 빌드 때 미리 계산해 바이너리와 JSON 파일로 만들어 둡니다. 런타임에는 Rust로 만든 WebAssembly 모듈이 연산을 맡고, 41KB짜리 Canvas 2D 렌더러가 화면을 그립니다.

| 파일 | 규모와 설정 | 역할 |
| --- | --- | --- |
| `pos.bin` | 시드 20260917 고정 | 황금각 피보나치 나선 레이아웃 좌표 |
| `graph.bin` | 932개 노드, 무방향 엣지 1,899개 | 압축 희소 행(Compressed Sparse Row, CSR) 인접 리스트 형식의 구조 엣지 |
| `related.bin` | 엣지 2,675개 | 본문과 제목 기반 의미 유사도 추천 엣지 |
| `meta.json` | 빌드 시각, SHA-256 | 18개 섹션 목록과 빌드 무결성 검증 메타데이터 |
| `search.json` | 175KB | 제목, 경로, 한글 초성 검색 인덱스 |
| `excerpts.json` | 130KB | 사이드바에 표시할 본문 발췌 |

엣지는 두 종류입니다. `graph.bin`은 구조 엣지를 CSR 형식으로 담으며, 방향 기준으로 세면 3,798개입니다. `related.bin`은 내용이 비슷한 노트를 잇는 추천 엣지를 담습니다. 설정값은 `related_top_k: 8`, `min_score: 0.04`입니다.

## 읽기 페이지는 JavaScript 번들 없이 어떻게 동작하나요?

Hugo 0.166.0이 빌드 때 수식과 코드 하이라이팅까지 HTML로 만들어 둡니다. 그래서 노트와 섹션 허브 페이지는 외부 JavaScript 번들을 싣지 않고, 테마를 초기화하는 인라인 스크립트만 실행합니다.

- **수식**: KaTeX 수식을 빌드 때 HTML로 변환하므로 클라이언트에서 수식을 파싱하는 지연이 없습니다.
- **코드**: Hugo의 Chroma가 코드 블록을 하이라이팅합니다.
- **URL**: `uglyURLs = true` 설정으로 `.html`이 붙은 정적 경로를 만듭니다.

노트 페이지는 위에서 아래로 다섯 요소가 이어집니다.

1. 브레드크럼
2. 제목
3. 메타 줄(단어 수, 예상 읽기 시간, GitHub 원문 링크)
4. 본문
5. 이전 노트와 다음 노트 링크

## 디자인 토큰: 모노스페이스와 그림자 없는 레이아웃

그림자와 그라디언트를 쓰지 않는 모노스페이스 레이아웃입니다. 본문 폭 640px, 본문 글자 17px, 줄간격 1.45를 기준으로 삼고 경계는 1px 선으로 구분합니다.

| 항목 | 값 |
| --- | --- |
| 본문 폭 | 640px |
| 글꼴 순서 | Geist Mono, JetBrains Mono, ui-monospace, Pretendard Variable, monospace |
| 글자 크기 | 본문 17px, 그래프 페이지 15px, 코드 15px |
| 제목 크기 | h1 36px, h2 22px, h3 19px |
| 여백 단계 | 4, 8, 12, 16, 24, 32px |
| 경계와 곡률 | 1px 실선, 그림자 없음. 아바타와 상단 아이콘 버튼만 원형 |

다크 모드 배경색은 일반 페이지가 `#000000`, 그래프가 `#090717`로 서로 다릅니다. 그래프는 그 위에 시드 기반 난수로 별빛을 그리고 허브 노드에는 반투명 후광을 입힙니다. 노드 색은 18개 섹션에 맞춘 18색 팔레트를 씁니다.

## 내 사이트에 지식 그래프를 넣는다면 참고할 점

estudy의 구성에서 참고할 설계 판단을 정리했습니다.

- 무거운 스크립트는 그래프 페이지 한 곳에만 두고 읽기 페이지는 정적 HTML로 유지합니다.
- 좌표와 엣지는 빌드 때 계산해 시드를 고정한 좌표 파일과 CSR 엣지 파일로 만들어 둡니다.
- 구조 엣지와 의미 유사도 엣지를 다른 파일로 나눕니다.
- 검색 인덱스에 한글 초성을 넣습니다.
- 검색, 화면 맞춤, 이웃 보기처럼 자주 쓰는 동작에 키보드 단축키를 하나씩 배정합니다.
- 좁은 화면에서는 사이드바를 캔버스 아래로 내립니다.

유사도 설정값을 바꾸면 엣지 밀도가 어떻게 달라질지 따져 보는 과제는 [estudy 실습 가이드](/posts/estudy-hands-on-lab-guide)에 있습니다.

## 자주 묻는 질문

### 모바일에서도 지식 그래프를 볼 수 있나요?

볼 수 있습니다. 화면 폭이 820px 이하이면 사이드바가 아래로 내려갑니다.

### 한글 초성으로 검색할 수 있나요?

검색할 수 있습니다. `search.json`에 제목과 경로, 초성을 분리한 인덱스가 들어 있어 입력과 동시에 결과를 찾습니다.

### 다크 모드는 어떻게 바꾸나요?

상단 테마 버튼을 누르면 system, light, dark 순서로 바뀝니다. 사이트는 선택한 테마를 브라우저의 `localStorage`에 저장합니다.
