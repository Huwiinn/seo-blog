버튼 모션은 멋지게 움직여 달라는 말 대신 모션의 이름으로 요청합니다. 물감이 흘러내리는 버튼부터 커서에 끌려오는 버튼, 테두리가 그려지는 버튼까지 9개에 이름이 하나씩 있습니다. 이름부터 말하고, 원하는 모양이 아닐 때 동작 설명 한 줄을 붙이는 순서입니다.

버튼 하나를 두고 수정을 거듭하면 토큰만 써 버립니다. 이름을 말하면 원하는 버튼을 더 빨리 얻습니다. 바이브코딩(Vibe Coding)에 바로 쓰도록 이름 9개, 버튼 역할별 선택 기준, 요청 예시 순서로 실었습니다.

## 버튼 모션 용어 9개 한눈에 보기

버튼 모션 9개는 마우스를 올리거나 누를 때 무엇이 변하는지에 따라 세 묶음으로 나뉩니다. AI에는 표의 영문 이름을 그대로 전달합니다.

| 용어 | 영문 이름 | 동작 | 어울리는 곳 |
| --- | --- | --- | --- |
| 웻 페인트 | Wet Paint Button | 버튼 아래로 물감이 흘러내리고, 마우스를 올리면 색이 진해짐 | 가입 버튼 |
| 인크립트 | Encrypt Button | 글자가 기호로 섞였다가 왼쪽부터 한 글자씩 돌아옴 | 보안·인증 버튼 |
| 닷 익스팬드 | Dot Expand Button | 작은 점이 화살표가 든 원으로 커지고 버튼 배경이 검게 반전됨 | 시작하기 버튼 |
| 마그넷 | Magnet Button | 버튼이 커서 쪽으로 끌려오고 둘레의 글자 고리가 회전함 | 원형 플로팅 버튼 |
| 햄버거 | Hamburger Button | 세 줄 아이콘이 돌면서 X 모양으로 바뀜 | 모바일 메뉴 버튼 |
| 스플래시 | Splash Button | 마우스를 올리면 바깥 링이 번지며 사라지고, 누르면 깊이 눌림 | 참여 버튼 |
| 샤이니 | Shiny Button | 커서를 따라 은은한 흰 빛이 표면 위를 움직임 | 구매 버튼 |
| 드로우 아웃라인 | Draw Outline Button | 테두리가 위쪽부터 시계 방향으로 한 변씩 그려짐 | 문의 버튼 |
| 스포트라이트 | Spotlight Button | 밝은 원이 커서를 따라오고 겹친 글자의 색이 반전됨 | 어두운 배경의 강조 버튼 |

메뉴와 텍스트, 차트에 쓰는 이름까지 함께 보려면 [UI 모션 용어 사전](/posts/ui-motion-dictionary)을 참고하면 됩니다.

## 버튼 역할에 맞는 모션은 어떻게 고르나요?

버튼이 페이지에서 맡은 역할을 먼저 정합니다. 전환을 이끄는 행동 유도 버튼(CTA)에는 눈에 띄는 모션을, 보조 버튼에는 변화가 분명하고 차분한 모션을 배정합니다. 효과가 화려한 버튼이 여럿이면 시선이 흩어집니다.

| 버튼 역할 | 예 | 맞는 모션 |
| --- | --- | --- |
| 전환을 이끄는 주 버튼 | 가입, 시작하기, 구매 | 웻 페인트, 닷 익스팬드, 샤이니, 스포트라이트 |
| 탐색을 돕는 보조 버튼 | 모바일 메뉴, 문의 | 햄버거, 드로우 아웃라인 |

주 버튼은 페이지 분위기로 한 번 더 좁힙니다. 다크 모드라면 스포트라이트를, 고급스러운 쇼핑몰이라면 샤이니를 고르는 식입니다.

### 표면과 글자가 변하는 버튼

버튼의 모양이나 글자, 안쪽 도형이 직접 변하는 묶음입니다. 웻 페인트는 갓 칠한 페인트처럼 물감 방울이 버튼 아래로 흘러내립니다. 마우스를 올리면 버튼 색이 한층 진해집니다. 디자인 에이전시처럼 개성을 드러내는 서비스의 가입 버튼에 어울립니다.

인크립트는 글자를 기호로 뒤섞은 뒤 왼쪽부터 차례로 원래 문구로 되돌립니다. 보안 솔루션이나 개발자 대시보드의 인증 버튼에 맞습니다. 닷 익스팬드는 버튼 왼쪽의 작은 점이 화살표가 든 원으로 커지면서 배경이 검정으로, 글자가 흰색으로 바뀝니다. 구독형 소프트웨어(SaaS) 랜딩 페이지의 시작하기 버튼에 씁니다.

### 커서와 클릭에 반응하는 버튼

커서 위치나 누르는 동작에 바로 반응하는 묶음입니다. 마그넷은 커서가 다가오면 버튼이 자석처럼 끌려오고, 둘레의 글자 고리가 회전합니다. 인터랙티브 포트폴리오의 원형 버튼에 어울립니다.

햄버거는 세 줄 메뉴 아이콘이 회전하며 닫기 모양으로 바뀌는 버튼입니다. 누르면 위아래 줄이 교차하고 가운데 줄은 사라집니다. 모바일 메뉴를 열고 닫는 자리에 씁니다. 버튼을 누른 뒤 펼쳐지는 메뉴의 움직임은 [메뉴 모션 이름 9개](/posts/menu-motion-names)에서 고르면 됩니다.

스플래시는 마우스를 올리면 버튼이 조금 커지고 바깥 링이 번지듯 사라집니다. 누르는 순간에는 꾹 눌렸다가 튀어 오릅니다. 웨비나 신청이나 프로모션처럼 바로 참여를 받는 버튼에 맞습니다.

### 빛과 테두리로 강조하는 버튼

버튼 크기는 그대로 두고 빛이나 테두리 선, 글자 색을 바꿔 강조하는 묶음입니다. 샤이니는 커서를 따라 은은한 흰 빛이 버튼 표면을 스칩니다. 상품 상세 화면의 구매 버튼에 어울립니다. 결제 버튼의 로딩 표시처럼 결제 단계에 쓰는 이름은 [결제 화면 모션 이름 9개](/posts/checkout-motion-names)에 따로 정리했습니다.

드로우 아웃라인은 평소에는 테두리가 없습니다. 마우스를 올리면 테두리가 위쪽부터 시계 방향으로 한 변씩 그려져 사각형이 됩니다. 절제된 인상이어서 문의 버튼에 씁니다. 스포트라이트는 어두운 버튼 위에서 밝은 원이 커서를 따라다니고, 원과 겹친 글자만 색이 반전됩니다. 다크 모드 랜딩 페이지의 강조 버튼에 맞습니다.

## 버튼 모션은 AI 코딩 도구에 어떻게 요청하나요?

두 단계로 요청합니다. 먼저 대상 버튼과 영문 이름만 말합니다. 결과가 의도와 다르면 언제 무엇이 변하는지를 한 줄로 덧붙입니다.

Cursor나 Claude Code, v0 같은 AI 코딩 도구에 요청할 때 쓰는 방식입니다. 1단계는 이름만으로 충분한지 확인하는 요청입니다.

```text
첫 화면의 시작하기 버튼에 dot expand button을 적용해 줘.
```

2단계에서는 마우스를 올릴 때인지 누를 때인지와 핵심 변화를 적습니다.

```text
상담 문의 버튼에는 draw outline button을 써 줘.
마우스를 올리면 테두리가 위쪽부터 시계 방향으로 한 변씩 그려지게 해 줘.
```

커서에 반응하는 모션은 터치 화면에서 어떻게 보일지도 함께 요청합니다.

```text
상품 상세의 구매 버튼을 shiny button으로 만들어 줘.
터치 화면에서는 버튼을 누를 때 같은 광택이 보이게 해 줘.
```

구현 방식까지 정해 두고 싶다면 기술 키워드를 한 줄에 넣습니다. 스포트라이트의 글자 색 반전에는 `mix-blend-mode: difference`를 지정하는 식입니다. 햄버거의 X 변환에는 `rotate(45deg)`와 `rotate(-45deg)`를 씁니다.

## 적용 전 점검 목록

한 화면에 9개를 모두 넣으면 보는 사람이 피로해집니다. 모션을 고른 뒤에는 아래 네 가지를 확인합니다.

1. **한 화면의 모션은 2~3가지로 제한합니다.** 첫 화면에는 주 버튼 하나와 보조 버튼 하나만 조합합니다. 주 버튼에는 닷 익스팬드나 스포트라이트를, 보조 버튼에는 드로우 아웃라인을 씁니다.
2. **터치 화면의 대안을 넣습니다.** 마그넷, 샤이니, 스포트라이트는 마우스 커서 위치에 의존합니다. 모바일에서는 누를 때 같은 피드백이 보이도록 요청합니다.
3. **동작 줄이기 설정을 따릅니다.** 웻 페인트나 인크립트처럼 움직임이 많은 버튼이 대상입니다. `prefers-reduced-motion: reduce` 환경에서는 단순한 색상 전환으로 바꿉니다. 애니메이션에 민감한 사용자를 위한 조치입니다.
4. **원하는 모양이 분명하면 이름과 동작을 한 번에 보냅니다.** 두 단계를 한 번의 요청으로 합쳐 다시 설명하는 일을 줄입니다.
